## 3. Topic deep-dives

### auto_annotation v4 (aav4) — clean rewrite

**Status:** shipped, supersedes aav3 (which itself was a rewrite of aav2 earlier in this window)
**Window activity:** 14 commits, ~25k LOC in `data_miner/auto_annotation_v4/` (85 Python files), 19 test files

**Why it happened (per project memo):** v3 had Redis Streams bugs (stale messages, cross-job contamination, SETID stomping, infinite re-queue). File checkpoints didn't scale (~800k files at 100k images). Config and model code were tangled.

**Progress:**
- **Phase 1:** 48 files built and importing cleanly. SQLite `CheckpointDB` (6 tables: `job_info`, `image_meta`, `proposals`, `stages`, `work_queue`, `failures`) replaces both Redis Streams *and* file checkpoints.
- **Phase 2:** Per-model detect — each detector claims a `detect:{model}` queue, writes to `proposals`, barrier-checks, then queues `detect:merge`. Force-rerun controls at job *and* model granularity.
- **Phase 3:** Async hardening — `needs_session` flag so non-HTTP workers don't burn aiohttp pools; `acquired` flag pattern instead of `async with` so CancelledError during semaphore acquire doesn't trigger a bogus release; two-phase shutdown (cooperative 30s grace → forced cancel).

**Key accomplishments:**
- Eliminated Redis dependency from the pipeline (one fewer service to operate).
- Pipeline now resumable from any stage on any subset of models without bespoke cleanup.
- 3 distinct reviewer-found blockers fixed during Phase 2/3 (compound-stage work_queue mismarking, `clear_downstream` LIKE-pattern miss, semaphore double-release on cancel).

**Next:**
- Pre-existing 13 GPU-bound test failures (sam3_dart / gdino batching) and 4 unrelated test failures still on the books — none introduced by this rewrite, but they should be triaged.

### Manual review system (Label Studio + ML backend + smart tools)

**Status:** shipped, live-validated on Caifu_Center_Fewer_2 clip
**Window activity:** 2 deep sessions (~22k JSONL lines combined), 18 commits, ~15.6k LOC in `manual_reviewer/`, 15 test files, **414 tests passing**

**Progress (8 phases + smart-tool extensions):**
- **Phase 1–4** (foundations): aav4 contracts (`Stage.HUMAN_REVIEW`, `HumanReviewResult`), pipeline_io readers/writers, `image_meta` dedup-column migration, LS docker-compose + labeling XML, image-mode cross-frame reconciler.
- **Phase 5/7 (merged):** SAM 3.1 server (above) — same backend feeds both aav4 and manual_reviewer.
- **Phase 6:** Rex-Omni detector exposed for aav4.
- **Phase 8:** Detector-policy doc separating aav4 ↔ manual_reviewer detector choice.
- **Smart-tool extensions** (collapsed to 4 user-facing tools after consolidation, commit `7e203d4`):
  - `smart_visual` (within-image visual prompting, hotkey `v`): SAM 3.1 `add_geometric_prompt` end-to-end with class-aware NMS dedup.
  - `smart_search` / `smart_click` / `smart_track`: text → boxes, point → mask, exemplar → cross-frame propagation via SAM 3.1 video tracker.
  - **`track_similar` + `propagate_now`** (Apr 30, two-phase): reviewer draws one exemplar, gets all in-image similars as drafts; on accept, fires multi-seed `/track` to all sibling tasks in one call. **Live result: 6 propagations from 2 seeds × 6 siblings on Caifu_Center_Fewer_2.**

**Key accomplishments:**
- Tests grew 281 → 414 over the window across smart_track (+26), track_similar/propagate_now (+11), and earlier additions.
- Single-source-of-truth dedup module (`ml_backend/dedup.py`) — IoU/NMS/dedup_against funcs reused by 4 routes; class-aware so person-on-forklift is preserved.
- ML backend kept as a *pure protocol adapter* (no torch/sam3/transformers import) — all inference flows through SAM 3.1 HTTP. Easier to operate; Dockerfile is light.
- LS XML rendered from `classes.txt` via `build_labeling_config.py` (no hand-edits) — keeps labels in lockstep with the dataset definition.

**Next:**
- DINOv3 `propagate_static` lib still exists at `reconcile/propagate_static.py` but is *not* wired to a UI button (smart_track now covers the static-object case). Safe to keep dormant.
- Optional: tracker-based reconcile in headless `run_reconcile.py` (~200 LoC + ~100 LoC tests). Lower priority.
